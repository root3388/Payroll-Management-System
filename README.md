# نظام تسيير الأجور (Payroll Management System)
## برنامج إدارة الرواتب والأجور للشركات

### 🛠️ تقنيات المشروع
- **اللغة**: Delphi (Object Pascal)
- **قاعدة البيانات**: PostgreSQL
- **واجهة المستخدم**: VCL (Visual Component Library)

---

## 📁 محتويات المشروع

### 1. **قاعدة البيانات** (`Database/`)
- Scripts SQL لإنشاء الجداول
- الجداول الأساسية للنظام
- الفهارس وعلاقات البيانات

### 2. **نظام Core** (`Core/`)
- `uDatabaseConnection.pas` - إدارة الاتصال بقاعدة البيانات
- `uConstants.pas` - الثوابت العامة للنظام
- `uHelper.pas` - الدوال المساعدة والعامة

### 3. **الواجهات** (`Forms/`)
- نماذج تسجيل الدخول
- نماذج إدارة الموظفين
- نماذج حساب الرواتب
- نماذج الإجازات والحضور

### 4. **التقارير** (`Reports/`)
- تقارير الرواتب
- تقارير الموظفين
- تقارير الحضور والإجازات

### 5. **الوحدات** (`Units/`)
- وحدات معالجة بيانات الموظفين
- وحدات معالجة الرواتب
- وحدات الحسابات والعمليات

## 🚀 البدء السريع

### المتطلبات:
- Delphi 7 أو أحدث
- PostgreSQL 10 أو أحدث
- SQL Explorer أو أي أداة إدارة قواعد بيانات

### خطوات التثبيت:

1. **استنساخ المشروع**:
```bash
git clone https://github.com/root3388/Payroll-Management-System.git
cd Payroll-Management-System
```

2. **تثبيت PostgreSQL** (إذا لم يكن مثبتاً):
```bash
# على Windows
# تحميل من: https://www.postgresql.org/download/windows/
```

3. **إنشاء قاعدة البيانات**:
```sql
-- في PostgreSQL
CREATE DATABASE payroll_system;
```

4. **تشغيل Scripts البيانات**:
```bash
psql -U postgres -d payroll_system -f Database/create_tables.sql
```

5. **فتح المشروع في Delphi**:
- افتح ملف المشروع `.dpr`
- قم بتجميع البرنامج (Compile)
- شغل البرنامج (Run)
